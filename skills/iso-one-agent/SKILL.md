# ISO one 에이전트

고객사 자료는 **구글 드라이브**, ISO 심사 서류의 원본 데이터는 **iso-one** 웹앱에 있다.
이 스킬은 드라이브 자료를 읽어 iso-one 칸에 맞춰 정리한 뒤 **iso-one 우편함(`iso_inbox`)에 보낸다**. iso-one이 열릴 때(어느 기기든) 반영한다.

- 에이전트는 iso-one 데이터를 직접 고치지 않는다 — 우편함에 쓰기만(열린 화면이 저장하며 덮어쓰는 충돌 방지).
- iso-one은 **빈 칸만 채운다.** 이미 있는 값은 덮어쓰지 않고, 다르면 결과에 「차이」로 남긴다 → 사람이 화면에서 고른다.
- iso-one에 없는 업체는 새로 등록한다(`createIfMissing`).
- 규격 원문: iso-one 저장소 `docs/ISO_INBOX_SPEC.md` v2 §6.

## 순서

### 1. 기업 확정
- `company_find`(SG Todo-List)로 사업자번호를 확정한다. 후보가 여럿이면 사용자에게 고르게 한다. CRM에 없으면 「SGCRM에 기업 먼저 등록」을 안내하고 멈춘다.
- **작성자(author)** — 정석진·김학미·공동. 대화에 없으면 먼저 묻는다.

### 2. 드라이브 자료 읽기 (Google Drive 커넥터)
1. 업체카드: `search_files` `title contains '업체카드' and title contains '<업체명 핵심어>'` → `NNN_업체카드_업체명.md`를 `read_file_content`.
2. 부족하면 같은 업체 폴더(업체카드 §8에 폴더 ID가 있음)의 `사업자등록증`·`4대 사회보험 사업장 가입자 명부`·`조직도` PDF를 읽는다.
3. 업체카드가 없으면 `title contains '<업체명>'`으로 사업자등록증부터 찾는다(신규 업체카드 작성은 sg-client-card 스킬).

### 3. 칸 맞추기 — `profile`
| iso-one 칸 | 키 | 어디서 |
|---|---|---|
| 업체명·대표자 | `name` `ceo` | 사업자등록증(정식 상호 「주식회사 ○○」) |
| 주소·전화·팩스 | `addr` `tel` `fax` | 사업자등록증·업체카드 |
| 설립일 | `founding_date` | 개업일(YYYY-MM-DD) |
| 종목·업태 세부 | `item` `ind_detail` | 사업자등록증 종목·업태 그대로 |
| 업종 | `ind` | 아래 「업종 고르기」 |
| 인증범위 | `scope` | 사용자가 정한 범위(없으면 묻는다) |
| 인원 | `emp_total` `emp_exec` `emp_reg` `emp_day` `emp_out` | 4대보험 명부(숫자만) |
| ISO 담당자 | `mgr` `mgr_title` `mgr_dept` `mgr_hp` `mgr_email` | 사용자·업체카드 |
| 안전보건 담당자 | `safety_mgr` | 사용자(45001 진행 시) |
| 홈페이지·우편번호 | `homepage` `addr_zip` | 자료에 있을 때만 |
| IAF 코드·세부코드 | `iaf` `iaf_sub` | 사용자(세부코드는 KSIC 4~5자리, 예 `1083`) |
| 관리번호 | `mgno_q` `mgno_e` `mgno_s` | 사용자(접두어 없이 `0614`, 진행 규격 칸만) |
| 부적합 시정조치 일자 | `ncr_action_date` | 2단계 종료일 + 사용자가 말한 보완 기간 |
| 부서명·주요 고객·생산설비·공정순서 | `dept_names` `customer` `prod_facility` `process_order`… | 조직도·업체카드에 분명할 때만 |
| 근무형태·설계 | `shift`(1교대·2교대·3교대·기타) `design`(있다·없다) | 분명할 때만 |

메시지 바깥 칸: `certs`(규격) · `atype`(최초심사·사후심사(1차)·사후심사(2차)·갱신심사) · `s1Date` · `s2Date` · `createIfMissing`(기본 true) · `assignee`(새 등록을 맡을 iso-one 로그인 이메일, 보통 sgceo@sgsolutionss.com) · `ref`(예 `drive:004_업체카드_(주)영심`).

**업종 고르기** — iso-one 12종 중 하나. 사업자등록증 업태보다 **인증받을 활동(인증범위)** 기준:
식품 제조·가공 → 식품업 · 일반 제조 → 제조업 · 화학·금속 → 화학·금속제조업 · 건설·공사 → 건설업 · 소프트웨어·IT → 정보통신업 · 도소매·유통 → 도소매업 · 운송·물류 → 운수·물류업 · 폐기물·환경 → 환경·폐기물처리업 · 병원 → 의료 · 학원·교육 → 교육 · 금융·보험 → 금융 · 그 밖의 서비스 → 서비스업.
(예: 영심 — 업태는 「전문·과학기술서비스업/도소매업」이지만 인증범위가 조미료 제조라 식품업.) 애매하면 후보 2개를 들어 묻는다. 업종에 따라 법규·목표·부적합 문구가 바뀐다.

**인원** — 4대보험 가입자 수가 기준. 대표가 명부에 없으면 「대표 포함 몇 명으로 할지」 묻는다(ISO 조직원수는 보통 대표 포함).

### 4. 넣지 않는 것
- 업체카드에서 **⚠확인 필요·미정·추정** 표시가 붙은 값.
- **대외 문서 금지 내부 메모** — 매각·지주회사·지분·주주·개인 차입·신용·보험·개인 특허 명의 등. profile의 모든 칸은 심사보고서·매뉴얼에 그대로 찍힐 수 있다.
- 주민번호·생년월일·개인 이메일 같은 개인정보(ISO 담당자 연락처는 사용자가 말했을 때만).
- 모르는 칸은 빈 문자열로 넣지 말고 **아예 뺀다**.

### 5. 아는 것 먼저 보내기
- 드라이브로 확인한 값과 대화에서 이미 들은 값만으로 `iso_profile`을 보낸다. **모르는 칸을 미리 묻지 않는다** — 무엇이 비었는지는 iso-one이 알려 준다(이전 심사 때 넣어 둔 값도 iso-one에 있으므로).
- 보내기 전에 보낼 내용을 **표 하나로 보여 주고** 확인받는다(공유 데이터에 쓰는 일).
- 호출: `company`, `author`, `certs`, `atype`, `s1Date`, `s2Date`(아는 경우), `profile`, `createIfMissing`, `assignee`, `ref`.
  - 거절되면(모르는 칸·틀린 값) 메시지대로 고쳐 다시 보낸다. 답의 ⚠ 주말 경고는 그대로 전한다.
  - 인증서 발급·심사 끝남·불합격 같은 **소식**은 이 도구가 아니라 `iso_update`.
- 「iso-one을 한 번 열면 반영됩니다(PC든 휴대폰이든)」라고 안내한다.

### 6. 접수표 — iso-one이 알려 준 빈 칸만
- 반영 뒤 `iso_update_status company=<업체>`를 보면 결과 아래에 **빈 필수 칸 / 빈 권장 칸**이 `라벨(키)`로 나온다. ⏳ 대기면 아직 iso-one을 안 연 것 — 열어 달라고 하고 기다린다.
- 이 목록으로 **접수표(질문지)** 를 만든다. 보관용 문서가 아니다 — 정보는 모두 iso-one에 저장된다.
  - **필수**(없으면 심사 진행·서류 출력 불가)를 위에, **권장**(비어도 출력은 되지만 보고서가 허술)을 아래에.
  - 칸마다 답 예시를 붙인다. 예) `IAF 세부코드(iaf_sub)` — KSIC 4~5자리 「1083」 / `1단계 심사일(s1Date)` — 영업일 「2026-10-01」 / `상근직 인원(emp_reg)` — 숫자
  - 채팅에 표로 보여 준다. 고객사에 보내 받아야 한다고 하면 같은 표를 메일 문안(또는 구글 문서)으로 만들어 준다 — 업체 폴더에 따로 모으지 않는다.
- 답을 받으면 **답한 칸만** 다시 `iso_profile`로 보낸다(키 그대로 · `s1Date`·`s2Date`는 바깥 칸). 「모름·해당 없음」은 보내지 않는다.
- 다시 `iso_update_status` → **빈 필수 칸이 없을 때까지** 반복. 「필수 칸 모두 채움」이 나오면 끝.
- **ISO 심사일은 영업일만.** 주말·공휴일(한글날·대체공휴일 포함)이 끼면 보내기 전에 바로잡자고 말한다. 여러 날이면 `2026-10-08~2026-10-09`.

### 7. 마무리 안내
- 결과의 **「기존 값과 달라 그대로 둠」** 항목은 하나씩 보여 주고 iso-one 정보입력에서 고를지 묻는다.
- 자동으로 채워지는 것은 묻지 않는다: 법규·목표·문서 수·심사일수(M/D)·영문 변환·내부심사원·복잡성. iso-one 정보입력의 「2단계 기준 일정 자동역산」 버튼을 누르면 질의서·견적·신청·송부일이 채워진다고 덧붙인다.

## 커넥터가 없을 때
- `iso_profile` 도구가 안 보이면: 「새 대화를 열거나 설정 → 커넥터에서 SG Todo-List를 다시 연결해 주세요」. 정리한 표는 그대로 남겨 둔다.
- Google Drive 커넥터가 없으면 자료 파일을 올려 달라고 한다.

→ `iso_profile` company=216-86-03926, author=김학미, certs=9001·14001·45001, atype=최초심사, s1Date=2026-10-01, s2Date=2026-10-08, assignee=sgceo@sgsolutionss.com, ref=drive:004_업체카드_(주)영심,
